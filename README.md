# Club Marathon Management System

## Project Description

The Club Marathon Management System is a web-based application developed to manage marathon registration and participant information efficiently.

The system provides separate functionality for administrators and participants. It allows participants to register for the marathon, manage their details and payment information, while the administrator can manage participants, transactions and reports.

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- Python
- Flask
- SQLite
- Jinja2

## Main Features

### Admin
- Admin Login
- Admin Dashboard
- View Participants
- Edit Participant Details
- Manage Transactions
- View Reports
- Manage Marathon Registration

### Participant
- Participant Signup
- Participant Login
- Participant Registration
- Participant Dashboard
- Payment
- Receipt
- View Registration Details
